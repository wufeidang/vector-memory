# 记忆系统架构：原生记忆 vs 向量记忆

## 双系统架构

Hermes 使用**双记忆系统**，各司其职：

| 维度 | Hermes 原生记忆 | Vector-Memory |
|------|----------------|---------------|
| **用途** | AI 记关于你的事 | **你自己**记专业知识 |
| **容量** | ~2,200 字符 | 无限（硬盘） |
| **搜索** | 关键词匹配 | 语义搜索（向量嵌入） |
| **谁控制** | AI 自动管理 | **你**主动控制 |
| **可分享** | ❌ 绑死 Hermes | ✅ pip 包分享 |
| **自动注入** | ✅ 每次对话 | ❌ 需主动查询 |

## 最佳搭配策略

```
Hermes 原生记忆 (MEMORY.md)
├── 用户偏好（中文交流、称呼偏好）
├── 身份背景（物业工程维修、Nemo叔叔）
├── 项目概览（监控教程 8/12，消防教程 3/12）
├── 关键状态（记忆空间 89%，待办事项）
└── 约 10-15 条核心条目

Vector-Memory (向量数据库)
├── 故障知识库（设备故障及解决方案）
├── SOP 文档库（操作规程）
├── 巡检日志库（每日异常记录）
├── 技术教程文章（监控/消防系列全文）
├── 设备参数库（品牌型号参数）
└── 数百至数千条专业知识
```

## 使用场景示例

### 场景 1：故障排查

```
用户：海康摄像头画面一直闪怎么办？

→ 自动搜索 Vector-Memory（自动集成规则触发）
→ 返回：海康DS-2CD系列画面闪烁，检查电源适配器输出是否稳定

→ 同时检查原生记忆
→ 返回：用户偏好中文交流，是物业工程维修专业人士
```

### 场景 2：教程创作

```
用户：帮我写监控教程第 08 期，硬盘 SMART 检测

→ 搜索 Vector-Memory 获取 SMART 技术参数
→ 搜索 Vector-Memory 获取之前教程的风格参考
→ 搜索原生记忆获取用户偏好（中文、物业场景）
→ 生成文章并保存到 Vector-Memory 和原生记忆
```

### 场景 3：项目进度管理

```
用户：我们项目进展到哪了？

→ 搜索原生记忆获取进度快照
→ 返回：监控教程 8/12，消防教程 3/12，第 08 期刚完成
```

## 空间管理建议

### 原生记忆（MEMORY.md）

- **容量上限**：~2,200 字符
- **当前使用**：89%（1,966 字符）
- **管理策略**：
  1. 仅保留关键偏好和状态摘要
  2. 详细记录迁移到 Vector-Memory
  3. 定期审查并清理旧条目

### Vector-Memory

- **容量**：无限（受硬盘空间限制）
- **当前规模**：112 个集合，~1.4 MB
- **管理策略**：
  1. 按项目/主题创建独立集合
  2. 使用版本历史追踪变更
  3. 定期备份（`backup_memory.py`）

## 迁移路径

当原生记忆空间不足时：

1. **识别可迁移条目**：详细记录、技术文档、故障案例
2. **迁移到 Vector-Memory**：
   ```python
   from vector_memory import add_memory
   add_memory({
       "text": "详细记录内容...",
       "metadata": {"category": "monitor", "type": "tutorial"}
   })
   ```
3. **原生记忆保留摘要**：
   ```
   2026-05-21：监控教程第 08 期完成，详情见 Vector-Memory
   ```

## 自动集成规则

Vector-Memory 的自动集成规则（见 SKILL.md "自动集成规则"章节）确保在对话涉及以下话题时自动搜索：

- 设备型号、品牌 → 搜相关故障记录
- 故障现象 → 搜网络/录像相关
- 维修经验 → 搜消防/监控相关
- 技术参数 → 搜供电/配置相关
- 项目名称 → 切集合后搜索

---

**核心原则**：原生记忆是"你的数字名片"，Vector-Memory 是"你的专业知识库"。两者互补，不是替代关系。
