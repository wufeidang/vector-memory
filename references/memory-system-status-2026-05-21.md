## 六、memory_cli 结构

`memory_cli.py` 是**交互式菜单 CLI**，不是 argparse 子命令模式。

**可用功能：**
- `show_backup_list()` — 列出备份
- `create_backup()` — 创建备份
- `show_stats()` — 查看 24 小时统计
- `test_all()` — 全功能测试
- `show_help()` — 帮助

**启动方式：**
```bash
python ~/.hermes/scripts/memory_cli.py
```

## 七、注意事项

1. **记忆空间接近上限 (89%)** — 如需新增记忆，可能需要清理旧条目
2. **daily_noise_summary.py 已移除** — 功能与 opt-05 版本管理重叠
3. **Web UI 需 Windows 原生启动** — 在 PowerShell/CMD 中运行 `python app.py`，非 WSL
4. **auto-memory 已合并** — 事件驱动自动记忆功能已集成到 vector_memory 的自动集成规则中
5. **GPU 不支持 ML 加速** — GT 430 (1GB VRAM)，模型在 CPU 模式运行
6. **terminal 工具在 Windows 上可能超时** — 文件操作优先使用 `execute_code` 中的 Python `open()`
