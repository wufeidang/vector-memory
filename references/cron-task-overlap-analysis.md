# Cron 任务与记忆系统优化重叠分析

## 背景

2026-05-21 用户询问：记忆系统已优化完成，Cron 中部分任务是否可以移除。

## 当前 Cron 任务清单

| 任务 | 频率 | 脚本 | 与记忆系统关系 |
|------|------|------|----------------|
| 每日噪声检测 | 09:00 | `daily_noise_summary.py` | **重叠** — 仅检测精确重复 |
| 每日记忆摘要 | 08:00 | `daily_memory_summary.py` | **重叠** — 摘要功能 |
| 每小时记忆同步 | 每小时 | `sync_memory.py` | **重叠** — 同步到向量存储 |
| 每小时 Feishu Token 刷新 | 每小时 | `refresh_feishu_token.py` | 无关 |
| Token 用量日报 | 23:00 | `token_tracker.py` | 无关 |

## 重叠分析

### 1. 噪声检测 (`daily_noise_summary.py`)

**功能**：扫描记忆数据库，检测重复记忆，生成报告。

**局限**：
- 仅检测**精确重复**（`content1 == content2`）
- 语义相似度检测代码被注释掉（需要向量存储访问）
- 报告仅本地保存，不主动推送

**与优化重叠**：
- Vector-Memory opt-05 已实现重复检测与摘要
- `vector_memory.py dedupe` 命令支持更完善的去重

**建议**：可移除，改用 `vector_memory.py dedupe` 或手动搜索。

### 2. 每日记忆摘要 (`daily_memory_summary.py`)

**功能**：生成每日记忆摘要。

**与优化重叠**：
- auto-memory 技能定义"每天首次对话时自动生成昨日摘要"
- 用户说"今天有什么" / "总结一下" 可触发

**建议**：可移除，改用 auto-memory 事件驱动模式。

### 3. 每小时记忆同步 (`sync_memory.py`)

**功能**：同步记忆到向量存储。

**与优化重叠**：
- Vector-Memory 的 `add_memory` / `add_batch` 直接写入向量存储
- 无需额外同步步骤

**建议**：可移除，除非有特殊的同步需求（如跨设备同步）。

## 决策建议

| 任务 | 建议 | 理由 |
|------|------|------|
| 每日噪声检测 | **移除** | 功能有限，与 opt-05 重叠 |
| 每日记忆摘要 | **移除** | auto-memory 已覆盖 |
| 每小时记忆同步 | **移除** | 直接写入向量存储即可 |
| Feishu Token 刷新 | **保留** | 独立功能，与记忆无关 |
| Token 用量日报 | **保留** | 独立功能，与记忆无关 |

## 移除方法

```bash
# 列出任务找到 job_id
hermes cron list

# 移除任务
hermes cron remove <job_id>
```

或通过 `cronjob` 工具的 `action='remove'`。
